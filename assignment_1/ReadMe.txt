第一次作业：通用面积计算器
组长：U202412693 王澔博

一、程序简介

本程序使用 Python 和 Tkinter 编写，可计算正方形、长方形、三角形和圆形的面积。
用户可以选择以厘米或英寸输入长度。程序会将长度统一换算为厘米，并以平方厘米输出面积；所有显示数值均保留 3 位小数。

二、运行方法

1. 安装 Python 3.9 或更高版本，无需安装第三方库。
2. 方式一：使用安装了“Python 开发”工作负载的 Visual Studio 打开“通用面积计算器.sln”，运行 main.py。
3. 方式二：在工程目录直接运行：python main.py

三、团队分工与模块介绍

1. 王澔博（组长）——main.py
   负责图形界面，提供图形选择、单位选择、长度输入、计算按钮、错误提示和结果显示，并整合其他成员模块。

2. 王菲——shapes.py
   负责图形类设计。使用 Shape 基类和 Square、Rectangle、Triangle、Circle 子类体现继承关系，并通过工厂函数创建图形对象。

3. 喻麒麟——area_calculator.py
   负责面积计算。实现正方形、长方形、三角形和圆形的面积公式，并提供统一的 calculate_area 接口。

4. 荣伊润——unit_converter.py
   负责长度输入校验和单位换算。检查空值、非数字与非正数，并按 1 英寸 = 2.54 厘米完成换算。

5. 杨婷——result_formatter.py
   负责结果输出。显示图形类型、输入长度和计算面积，并将长度与面积统一格式化为保留 3 位小数的厘米和平方厘米。

四、文件说明

main.py：程序入口及图形界面。
通用面积计算器.sln：Visual Studio 解决方案文件。
通用面积计算器.pyproj：Visual Studio Python 项目文件，启动文件为 main.py。
shapes.py：图形基类、子类及工厂函数。
area_calculator.py：四种图形的面积计算公式。
unit_converter.py：输入校验和英寸到厘米的换算。
result_formatter.py：计算结果格式化。
tests/test_area_calculator.py：面积计算模块测试。

五、功能要求对应情况

1. 支持选择正方形、长方形、三角形或圆形。
2. 根据图形类型提示输入边长、长和宽、底和高或直径。
3. 支持厘米和英寸两种输入单位。
4. 输出图形类型、换算后的厘米长度和平方厘米面积，均保留 3 位小数。
5. 提供完整的图形界面和输入错误提示。
